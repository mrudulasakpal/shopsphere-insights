# E-Commerce Insights Hub

Create a modern, professional, visually attractive static website for a college Data Warehouse & Data Mining project based on an E-Commerce Sales Data Warehouse.

Website Theme

The website should look like a combination of:

A modern e-commerce shopping website

An e-commerce business analytics dashboard

A college-level Data Warehouse project

Use a clean, premium UI with a white/light background, dark text, subtle shadows, rounded cards, and a professional accent color such as blue/purple.

The website must be fully static. Do NOT create a backend, database connection, login system, payment system, or real checkout. All data can be hardcoded/sample data.
